EUGENS SCHACH ARENA 4.8 — ОБЩИЙ СТОЛ КАК В «ТЫСЯЧА АРЕНА»

Новое:
— 🌐 Allgemeiner Tisch · 2 Spieler: автоматический поиск соперника.
— Первый игрок ждёт, второй подключается без кода.
— Можно выбрать одинаковое время для игры: 3, 5, 10 или 15 минут.
— Личные комнаты по коду / приглашению остаются.
— Шахматные задачи, компьютер, анализ и профили остаются в прежнем HTML.

ВАЖНО: Для автоматических общих столов НУЖЕН Node.js-сервер в составе архива.
Render Static Site не запускает server.js. Нужен ОТДЕЛЬНЫЙ Render Web Service.
Не удаляйте работающий Static Site до проверки нового адреса.

УСТАНОВКА:
1. Загрузите index.html, server.js и package.json в корень репозитория
   https://github.com/krimik1981-sudo/eugens-schach-arena
   (server.test.js загружать необязательно).
2. На Render нажмите + New → Web Service → Public Git Repository.
3. Введите ссылку https://github.com/krimik1981-sudo/eugens-schach-arena
4. Name: eugens-schach-online (или любое свободное).
5. Branch: main; Root Directory: пусто.
6. Build Command: npm install
7. Start Command: npm start
8. Instance Type: Free, если предлагается.
9. Deploy Web Service, затем проверьте новый адрес.

ВАЖНО ОГРАНИЧЕНИЕ:
— Для общего стола используется лёгкий сервер поиска пар и PeerJS/WebRTC для самих ходов.
— Бесплатный сервер Render может засыпать, а при перезапуске очереди ожидания теряются.
— Партии не синхронизируются со старым Netlify и не сохраняются в базе данных.
— Разрыв PeerJS-соединения потребует повторного подключения/новой комнаты.
— Это первый этап; постоянное хранение незаконченных онлайн-партий и вход по аккаунту, как в «Тысяча», потребуют отдельного обновления.
